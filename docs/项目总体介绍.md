# net_V 神经网络 ZCU104 部署项目 —— 总体介绍（2026-08-15 终版）

> 一句话：把轨道转移 RL 模型（7 层全连接，131.8 万参数，ELU）部署到 Xilinx ZCU104，
> 主机经以太网发送 7 维任务参数，板子 0.83ms 内返回 ΔV 预测，
> 与 PyTorch 浮点模型误差 ≤1.05 m/s（预算 15 m/s），与定点 golden model 逐 bit 一致。
> **全部阶段已完成并通过板上实测。**

---

## 1. 项目背景与目标

- 模型用途：由 7 维轨道转移任务参数（h0 初始轨道高度 km、I0 初始倾角 rad、
  Δh 高度差 km、ΔI 倾角差 rad、ΔΩ 升交点赤经差 rad、fmax 推力加速度 m/s²、
  tf 转移时间 s）预测最小转移代价 ΔV（m/s）。仅预测非奇异转移场景。
- 部署目标：Xilinx ZCU104（XCZU7EV-2FFVC1156），PL 做推理加速，PS 做归一化与
  网络通信（lwIP UDP），主机仿真平台经以太网调用。
- 指标：ΔV 允许误差 15 m/s（网络自身平均相对误差 ~2%）；无实时性要求
  （全局规划阶段调用，非实时控制环路）。

## 2. 模型与交付数据

- 结构：7→512（ELU）→ 512→512 ×5（ELU）→ 512→1（线性）。无 BN。
  MAC 数 1,314,816，总参数 1,317,889（含 bias 3,073）。
- 激活 ELU（α=1）：负支 eˣ-1 渐近 -1，输出恒 ∈(-1, 上限)。
- 交付文件（`神经网络部署输入(1)/`）：权重/偏置 txt（5 位有效数字，行=输出神经元）、
  归一化参数（z=(x-mean)/√var）、输入包络（`net_V_input_ranges.txt`）、
  1 组测试样本（逐层输出）、net_V.pt、说明 PPT。
- 实测动态范围（2 万组全包络采样，自研 golden model 统计）：
  归一化输入 [-3.0, +16.4]；隐藏层激活 [-1, ~3935]；ΔV [34, 9553]。
  **教训：单组交付样本（峰值 90）远不能代表全包络，量化定标必须采样统计。**

## 3. 总体结构（三级：PC / PS / PL）

```text
主机仿真平台（Python 客户端）
   ║  UDP 36B 请求：magic + seq + 7×float32 原始输入
   ▼
ZCU104 PS（Cortex-A53 裸机程序）
   归一化 z=(x-mean)/√var（double）→ 量化 Q6.10 int16
   启动时先把 82,464 个权重字经 AXI 写进 PL（URAM 上电空白）
   ▼  AXI4-Lite 寄存器（基址 0xA000_0000）
ZCU104 PL（net_v_axi → net_v_top → fc_engine，100MHz）
   7 层 FC 推理，82,547 拍 = 826µs
   ▼
PS 读 40bit 累加器原值 → 反量化 ΔV=acc×2⁻²⁰
   ║  UDP 20B 应答：magic + seq + float32 ΔV + status + infer_us
   ▼
主机收 ΔV
```

## 4. 定点量化方案（精度是设计出来的，不是试出来的）

- 位宽：权重 int16、激活 **int18**、输入 int16 Q6.10、累加器 40bit。
  （关键裁决：纯 int16 激活 p99.9=2.23 m/s 超预算；升 18bit 后 1.437 m/s 过线。
  DSP48E2 原生 27×18，18bit 无额外代价。）
- **逐层 Q 格式**（每层激活小数位 12/10/7/5/4/5，权重 Q1.15/Q2.14 逐层）：
  各层动态范围差 500 倍（layer_01 峰值 7.7 vs layer_05 峰值 3935），统一格式经
  2 万样本实验证明不可行（统一 frac=4 → p99.9 误差 49.6 m/s，超线 33 倍；
  仅统一权重也超线 5%）。详见 `docs/qformat_experiment.md`。
- 截位：逐层 CUT_POS（=[13,17,17,16,16,13]），右移前加半 LSB 四舍五入，饱和 clamp。
- ELU：LUT+线性插值，负支 [-8,0) 256 档（x≤-8 钳 -1，正支直通），
  5 张去重表共 1157 项 ≈ 2.3KB，纯组合逻辑时分复用 1 个单元。
- 输出层不截位：40bit 累加器原值送 PS 反量化，输出零部署损失。
- 精度验收（2 万样本）：ΔV 部署误差 p99.9=1.437 m/s、max=3.16 m/s
  （预算 15 的 1/10 自留线 1.5）。

## 5. RTL 架构

- `fc_engine.v`：单引擎时分复用跑 7 层。16 路输入并行（16 个 DSP）+
  4 级流水加法树（16→8→4→2→1）+ 40bit 累加 + bias + CUT_POS 截位 + 饱和 +
  ELU LUT；11 级流水线；层间 512×18bit×2 ping-pong 寄存器缓冲。
  并行度定义：层 → 输出神经元[0:511] → 输入组[0:31] → 组内 lane[0:15]。
- `weight_rom.v`：82,464 字 × 256bit（每字 16 个 int16 lane，按输出神经元连续），
  行为级数组 + `ram_style=ultra` → **84 块 URAM288**；地址 = 层基址+神经元×32+组号。
  **URAM 硅片不支持 bitstream 初始化**（综合排障实锤：XPM/行为级带 $readmemh
  静默回退 BRAM/分布式 RAM、blk_mem_gen 禁 coe），故权重由 PS 启动时经加载口
  （w_wr_*）写入一次。仿真路径保留 $readmemh（`ifndef SYNTHESIS` 隔离）。
- `bias_rom.v`：3,073×40bit，BRAM 初始化（随 bitstream）。
- `elu_lut.v`：组合 LUT+插值（见第 4 节）。
- `axi/net_v_axi.v`：AXI4-Lite 外壳（zynet 模板改造）。寄存器：CTRL(start/软复位)、
  STATUS(done)、X0~X6、RESULT_LO/HI、W_ADDR（自增）、W_D0~D7（组装 256bit）、
  W_COMMIT。
- BD：Zynq PS（ZCU104 板级预设）+ AXI 互联（自动协议转换）+ IP @ 0xA000_0000，
  时钟 PS PL0=100MHz。

## 6. 验证体系（分层 × 零容差 × 多环境）

**裁判来源**：Python golden model——定点 bit-true 路径与 RTL 语义逐条一致
（同 Q 格式、同舍入、同饱和、同 ELU 表），离线生成"标准答案" hex。

| 层 | 内容 | 结果 |
|---|---|---|
| golden 自身 | 阶段1 浮点对齐交付数据（27 项）；阶段2 定点语义手算对照（28 项）；ELU 边界（9 项） | 全 PASS |
| 单元 tb | signed_mac、simple_neuron（XSim） | PASS |
| 分层 tb | 27 案例 × 6 层 × 512 神经元逐 bit（82,944 次） | 0 不符 |
| 端到端 tb | 27 案例 40bit 输出零容差 | 27/27 |
| 单层调试 tb | `+SAMPLE +LAYER` 任意单层独立复跑 | 12/12 |
| AXI 外壳 tb | 权重口抽测+4 样本全链+软复位 | 12/12 |
| 环境 | iverilog 双环境 + Vivado 2018.3 XSim（GUI+批处理）三重 | 拍数全一致 |
| 板上 | 串口自检（acc7 逐 bit）+ UDP batch 27 组 | 全 PASS |

案例设计 27 组 = 典型（交付样本）+ 随机×10（seed 固定）+ 边界×16
（全 min/全 max/单维拉满或拉底）。边界实测：有害饱和 0 次，累加器峰值 2^33.2
（40bit 余量 5.8bit），边界样本误差最大 0.52 m/s。

## 7. 综合与上板

- 时序：纯 PL OOC **WNS=+2.297ns**；BD 系统集成后 **WNS=+1.277ns**（均 @100MHz）。
- 资源：URAM 84/96（87.5%）、DSP 21/1728（1.2%）、LUT 3.6%、FF 4.5%、BRAM 5/312。
- 启动镜像 BOOT.bin = FSBL → PMUFW → bitstream → app（SD 卡启动）。
- 板上实测：权重加载 82,464 字耗时 37ms；推理恒 826µs；UDP RTT 平均 1.14ms。

## 8. 以太网通信

- 协议：`docs/ethernet_protocol.md`（请求 36B / 应答 20B，全小端，含链路 echo
  自检与推理耗时打点）。板 192.168.1.10:5000，PC 192.168.1.100。
- PC 客户端 `sdk/pc_client/udp_client.py`（纯标准库）：ping / sample / batch
  / --selftest。batch 判定基准=定点 golden（容差 0.01 m/s），浮点误差作展示。
- 将来对接仿真环境：只改 IP/端口，协议与代码不变。

## 9. 排障记录（都值得复盘）

1. XSim 2018.3 不接受 always 循环内 mem[wire+integer] 下标（VRFC 10-536）→
   generate 铺平。
2. 行为级大 ROM + $readmemh → 综合内存爆炸 34GB（16GB 机器）→ 查明 URAM 不可
   bitstream 初始化 → PS 启动加载方案。
3. XPM 2018.3 对 ultra 静默回退 BRAM；blk_mem_gen 对 URAM 禁 coe；
   `synth_design -generic` 传字符串带引号触发 DRC 误报。
4. 工程模式 IP 需 generate_target + OOC 综合顺序；OOC run 的 hex 路径 hook。
5. xsct 2018.3：setlib 不落盘（改写 mss）、链接行继承需重建工程、SDK 导出用
   write_hwdef+write_sysdef（无 export_hardware）。
6. Vivado 仿真默认只跑 1000ns，需 Run All；$stop 会挂住批处理，用 $finish。
7. SD 卡接触不良导致启动失败（PS_ERR_OUT/PS_ERR_STATUS 红灯、DONE 不亮），
   擦金手指重插恢复；串口工具断电后需重开会话。
